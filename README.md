# hxwl-10 考古探方记录

遗址 → 探方 → 地层 / 遗迹单位 → 出土物 → 暂存箱 / 移交记录的现场档案。

## 技术栈

React 19 + Vite + TypeScript + CSS，领域逻辑为纯 TypeScript（无第三方运行时依赖）。

## 本地运行

```bash
npm install
npm run dev      # 开发端口 5110
npm test         # 领域规则断言（node:test，14 项）
npm run build    # 类型检查 + 生产构建
```

## 业务规则与实现

| 现场要求 | 实现 |
| --- | --- |
| 箱位按重量与件数排队 | `档案仓库.重排箱位`：未封箱箱按总重量降序、件数降序；空箱不占队，封箱出队留底 |
| 遗迹边界一改，未装箱归属马上失效重算 | `档案仓库.调整遗迹边界`：边界版本 +1，探方内未冻结件按新多边形与开口层位重新归属；坐标界内但层位不符不落遗迹 |
| 已签字移交的保留原依据 | 装箱瞬间冻结依据，封箱签字逐件写入 `移交记录.依据快照`；之后任何边界调整、迟到异读都不改账 |
| 断网记录按探方批次合并 | `合并批次`：按批次重放、时间序应用，`opId` 幂等去重 |
| 同一出土物坐标或层位两边不同 | 留两份读法生成 `归属冲突`，未装箱件置「待领队裁定」且禁止装箱；领队采用一份后重算归属。冻结账迟到异读只登记、不翻盘 |
| 同步失败按未完成明细重试 | `同步引擎.同步(批次, 未完成明细)`：第二轮只提交明细中的 op；区分「未应用失败」与「响应丢失（远端已生效）」 |
| 重放不增加移交记录 | 移交记录 id 由 opId 确定性派生（`YJ-<opId>`），远端按 opId 幂等，重放走「幂等命中」 |
| 旧档案无探方批次回填 | `回填旧档案`：按「遗址 + 发掘日」派生批次（同日同遗址归一批）；缺遗址/发掘日/探方/坐标/层位等先置「待核」，不猜测 |

## 目录

- `src/domain/types.ts` — 领域模型（遗址、探方、地层、遗迹、出土物、暂存箱、移交、冲突、断网操作）
- `src/domain/geometry.ts` — 多边形归属判定（射线法，边线算界内）
- `src/domain/repository.ts` — 档案仓库：归属重算、装箱排队、封箱冻结、裁定
- `src/domain/offline.ts` — 断网操作应用与探方批次合并
- `src/domain/sync.ts` — 模拟远端、未完成明细重试、幂等重放
- `src/domain/legacy.ts` — 旧档案批次回填与待核
- `src/domain/seed.ts` / `scenario.ts` — 基线数据与七阶段全流程推演（界面直接重放）
- `tests/domain.test.ts` — 规则断言
