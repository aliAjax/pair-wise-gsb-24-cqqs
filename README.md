# hxwl-10 考古探方现场档案

遗址 → 探方 → 地层 → 遗迹单位 → 出土物 → 暂存箱 的一体化现场档案，覆盖断网记录、边界调整与同步冲突。

## 技术栈

React + Vite + TypeScript + CSS，领域引擎为纯 TypeScript（`src/domain/`），测试用 Vitest。

## 本地运行

```bash
npm install
npm run dev      # 开发端口 5110
npm test         # 领域规则测试
npm run build
```

## 领域规则（src/domain/）

- **归属计算**（`archive.ts`）：出土物按坐标落入遗迹边界则归遗迹单位（同层位优先、面积小者优先），否则归地层；归属依据记录边界版本号。
- **边界调整**：遗迹边界一改版本号 +1，未装箱出土物的归属立即失效并按新边界重算；已装箱的保留装箱时归属；已签字移交的以移交记录快照为准，永不改写。
- **箱位排队**：暂存箱按剩余承重、剩余件数升序排队，装箱取队首能放下的箱子，都放不下自动开新箱（默认单箱 5000g / 20 件）。
- **断网同步**（`sync.ts`）：平板记录按探方批次（探方 + 发掘日 + 设备）合并；同一出土物坐标或层位两边不一致时两份都保留，登记冲突待领队裁定，裁定后按选定版本重算归属。
- **幂等重试**：移交记录按幂等键去重，重放不新增；同步失败后 `retryIncomplete` 只重发未完成明细。
- **旧档回填**（`legacy.ts`）：没有探方批次的旧记录按 遗址 + 发掘日 归并成批次；缺遗址、探方或发掘日的条目不强行归批，列入待核清单。

## 演示界面

首页按顺序执行六个步骤：装箱 → 签字移交 → H12 边界外扩 → 断网批次同步（含冲突与网络中断）→ 按未完成明细重试 → 旧档案回填；冲突面板可模拟领队裁定，审计日志记录每次归属变化。
